# SDDP Apartment

Public marketing website and a progressive CRM for SDDP Apartment in San Kamphaeng, Chiang Mai.

Guests can check live room availability, send an inquiry, and contact the team on phone, WhatsApp, or Line. Staff can follow those inquiries, convert a booked guest into a resident record, and check people out so the public room board updates.

## What is live now

- Customer website in English, Thai, and Burmese
- Live availability from resident records (no private guest data on the public page)
- Inquiry form into a staff pipeline: new → contacted → booked → moved in
- Encrypted passport storage after staff confirm consent
- Render free hosting for this first public launch

A later move to your own VPS is planned. Render's free disk is not permanent, so keep a copy of important resident records until that VPS is ready.

## Local preview

```bash
npm install
cp .env.example .env
# set ADMIN_PASSWORD and a 32-byte base64 GUEST_DATA_ENCRYPTION_KEY
npm run dev
```

Create an encryption key with:

```bash
openssl rand -base64 32
```

Open `/admin` on localhost to use the local preview login, or set `ADMIN_PASSWORD` and sign in with that password.

## Render (free)

1. Push this repository to GitHub.
2. In Render, create a **Web Service** from the repo, or use `render.yaml`.
3. Runtime: Node 22. Build: `npm ci && npm run build`. Start: `npm start`.
4. Set `ADMIN_PASSWORD` and `GUEST_DATA_ENCRYPTION_KEY` in the Render dashboard. `ADMIN_SESSION_SECRET` can be generated by Render.
5. `SDDP_DB_PATH` defaults to `./data/sddp.sqlite`.

The free instance sleeps after idle time. The first visit after sleep can take a short wait.

## VPS later

When you move off Render:

- Copy `data/sddp.sqlite` to the VPS
- Keep `SDDP_DB_PATH` pointed at a real disk
- Run `npm run build` and `npm start` behind Nginx or Caddy
- Put the custom domain on that VPS

This project does not use other websites or their git remotes.

## Optional alerts

Set `N8N_INQUIRY_WEBHOOK` and `N8N_WEBHOOK_SECRET` only if you want a separate staff alert. Inquiry and resident records still save in this app first. Passport numbers are never included in those alerts.
